following programs. They are separate programs that FreeX Media Server runs; each
keeps its own license.

    The license texts are in jre\legal.
    Source code: https://github.com/adoptium/jdk21u
    Project: https://adoptium.net

FFmpeg (ffmpeg.exe, ffprobe.exe), folder "ffmpeg"
    Build: "essentials" release build by Gyan Doshi (https://www.gyan.dev/ffmpeg/builds/)
    License: GNU General Public License v3.0 (the build contains GPL components
    such as x264); the license text is in ffmpeg\LICENSE.
    Source code of FFmpeg: https://ffmpeg.org/download.html and https://github.com/FFmpeg/FFmpeg
    Sources of the build: https://github.com/GyanD/codexffmpeg
    You may replace ffmpeg.exe and ffprobe.exe with other builds, or point
    ffmpeg.ffmpeg and ffmpeg.ffprobe in config.yml to them.
